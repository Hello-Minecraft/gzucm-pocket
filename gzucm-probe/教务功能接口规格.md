# 广中医教务系统功能接口规格（成绩 / 报名 / 教材 / 教室）

> 2026-10-28 实测。覆盖课程成绩、考级成绩、体测成绩、考试安排、选课报名、选订教材、教室借用申请。

## 0. 访问机制（最关键的一条）

**直接 GET 功能页一律被 302 弹回 `/new/welcome.page?ui=new`。** 所有功能页必须通过框架内的菜单点击以 iframe 方式打开。

```
GET /new/welcome.page?ui=new          ← 外层壳，里面是 iframe0 → /new/desktop
  → 点击 <a class="menuItem" href="/new/student/xskccj/main.page">课程成绩</a>
  → 框架内新建 iframe 加载 main.page
  → main.page 再嵌一个 iframe 加载 xccjList.page（真正的列表页）
  → 列表页发 POST 拿 JSON
```

菜单数据来自 `POST /new/desktop/getMenu`（返回 75 项，含 `menuname` / `menuurl` / `parentid` / `menulevel`，可直接建树）。

菜单项在 DOM 里是 `a.menuItem`，但**父级是折叠状态**，Playwright 的 `click()` 会因不可见失败，必须用 JS 原生 `element.click()`。

自动化工具的正确姿势：
1. `goto welcome.page`
2. `document.querySelectorAll('a.menuItem')` 按文本匹配，`.click()`
3. 监听 `page.on('response')` 抓子 frame 的 JSON

| 功能 | 菜单路径 | 数据接口 | 实测 |
|---|---|---|---|
| 课程成绩 | `new/student/xskccj/main.page` | `POST /new/student/xskccj/kccjDatas` | 83 条 |
| 考级成绩 | `new/student/xskjcj/xskjcjlist.page` | `POST /new/student/xskjcj/datas` | 5 条 |
| 体测成绩 | `new/student/xstccj` | `POST /new/student/xstccj/datas` | 4 条 |
| 考试安排 | `new/student/xsksrw/list.page` | `POST /new/student/xsksrw/paginateXsksrw` | 空 |
| 选课报名 | `new/student/xsxk/` | 无数据接口 | 非选课期 |
| 选订教材 | `new/student/xsxyjc/xsxyjcMain.page` | `POST /new/student/xsxyjc/queryYxjcDatas` | 25 条 |
| 教室借用申请 | `new/student/xsjssq/xsjssqMain.page` | `POST /new/student/xsjssq/xsjssqPaginate` | 空 |

统一的请求头（easyui 风格）：

```
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
X-Requested-With: XMLHttpRequest
```

响应统一是 `{"data":"","rows":[...],"total":N}`，分页参数 `page` / `rows` / `sort` / `order`。

## 2. 课程成绩

```http
POST /new/student/xskccj/kccjDatas

xnxqdm=&source=kccjlist&ismax=1&page=1&rows=60&sort=xnxqdm,kcmc&order=desc,asc
```

- `xnxqdm` 留空 = 全部学期
- `ismax=1` = 重修只取最高分（页面上"取最高成绩"勾选框）

字段字典（44 个）：

| 字段 | 含义 | 备注 |
|---|---|---|
| `kcmc` / `kcywmc` | 课程中文名 / 英文名 | |
| `kcdm` / `kcbh` | 课程代码 / 课序号 | |
| `zf` / `zcjfs` / `zcj` | 总成绩（多份冗余字段） | `zcjfs` 数值型，直接用 |
| `cjjd` | 绩点 | 3.70 这种两位小数 |
| `xf` / `zxs` | 学分 / 总学时 | |
| `xnxqmc` / `xnxqdm` | 学期名 / 学期代码 | `2025-2026-2` |
| `cjfsmc` / `ksxzmc` | 成绩方式 / 考试性质 | |
| `kcdlmc` / `kcflmc` | 课程大类 / 分类 | 实践课、理论课 |
| `xdfsmc` | 修读方式 | |
| `bz` | 备注 | 常带导入时间戳 |
| `ismax` / `isactive` | 是否最高分 / 是否有效 | 重修过滤用 |
| `wzc` / `wpj` | 未通过次数等统计 | |

## 4. 体测成绩

```http
POST /new/student/xstccj/datas
page=1&rows=60&sort=xnxqdm&order=asc
```

按项目分组，每项都有 `xx` 原值 / `xxpf` 分数 / `xxdj` 等级 三件套：

| 项目 | 原值 | 分数 | 等级 |
|---|---|---|---|
| 身高 | `sg` | — | — |
| 体重 | `tz` | `tzpf` | `tzdj` |
| 肺活量 | `fhl` | `fhlpf` | `fhldj` |
| 50 米 | `wsm` | `wsmpf` | `wsmdj` |
| 坐位体前屈 | `zwtqq` | `zwtqqpf` | `zwtqqdj` |
| 立定跳远 | `ldty` | `ldtypf` | `ldtydj` |
| 引体向上/仰卧起坐 | `ytxsorywqz` | `ytxsorywqzpf` | `ytxsorywqzdj` |
| 800/1000 米 | `yqmorbbm` | `yqmorbbmpf` | `yqmorbbmdj` |

另有：`zf` 总分、`dj` 总等级、`ycj` 学年成绩、`zycj` 总学年成绩、`teaxm` 测试教师、`cjbzmc` 成绩备注。

⚠️ 这个接口返回里含 `csrq`（出生日期）、`sfzh`（身份证号）、`dh`（电话）、`jtdz`（家庭地址）、`mzmc`（民族）。**移植时不要原样存库**，只取成绩相关字段。

## 6. 考试安排 / 教室借用（当前为空）

两者返回相同的空结构：

```json
{"data":"","rows":[],"total":0}
```

- **考试安排**：参数 `xnxqdm=202601&page=1&rows=60&sort=zc,xq,jcdm2&order=asc`。10 月底时期末考还没排，等教务排了就会有数据，接口本身是通的。
- **教室借用**：参数 `xnxqdm=202601&primarySort=+xnxqdm+desc+&page=1&rows=60&sort=jydm&order=asc`。暂无申请记录。

## 7. 选课报名（非选课期）

页面 `new/student/xsxk/` 能打开，但**没有任何数据接口被调用** —— 前端在等"选课批次"。广中医的选课是分轮次开放的（用户口述：从大一下开始可以选限选课和公选课），非选课期进去就是空壳。

要抓完整接口，得等选课窗口开放时再进去点一次。当前无法给出确切契约。

## 8. 教学校历（补上了学期起始日期）

之前课表接口拿不到「第一周周一」，只能手填。菜单里的「教学校历」把这个缺口补上了：

```http
POST /new/xlxx/data
xnxqdm=202601
```

返回 18KB 的二维表格，结构是「表头 + 每周一行」：

```json
{"code":0,"data":[[
   [{"type":"head","value":"周次"}, {"type":"xq","value":"日","fullText":"星期日"}, …],
   [{"type":"zc","value":"1","fullText":"第1周"},
    {"type":"day","fullText":"2026-09-06","month":"2026-09"}, …]
]]}
```

解析规则：每组第一行是表头（星期日→星期六），之后每行一周；周次在 `type=zc` 的 cell，日期在 `type=day` 的 cell。

实测 202601 学期解析出 **23 周**：

| 周次 | 起止 |
|---|---|
| 第 1 周 | 2026-09-06 ~ 09-12（周一 = **2026-09-07**） |
| 第 2 周 | 2026-09-13 ~ 09-19 |
| 第 19 周 | 2027-01-10 ~ 01-16 |
| 第 20 周 | 2027-01-17 ~ 01-23 |

**结论**：学期起始日可以从校历接口自动推导（第 1 周日期 + 1 天 = 第一周周一），不再需要手动配置。之前课表规格里那条"待定项"可以划掉了。

## 10. 移植建议

| 功能 | 优先级 | 说明 |
|---|---|---|
| 课程成绩 | P1 | 83 条一次拿全，按学期分组。绩点/学分可算加权平均 |
| 体测成绩 | P2 | 注意剔除身份证/电话/住址字段 |
| 考级成绩 | P2 | 结构简单 |
| 选订教材 | P2 | 与课表联动（每门课配了哪本教材） |
| 考试安排 | P1 | 接口已通，等教务排考即有数据 |
| 教室借用 | P3 | 低频 |
| 选课报名 | P3 | 需选课期才能抓，且涉及写操作（报名/退课），不建议自动化 |

**写操作一律不做**：选课、报名、申请类功能只做"查看入口 + 跳转原网页"，不在 App 里模拟提交。
