# v1.2.6 · 课表支持同一时段多门课

这一版只做了一件事，但做得很深：**课表里时间冲突的课，终于能看清了**。

## 之前是什么样

两节课节次有交集时，它们都画在同一个位置上，后画的盖住前画的。结果两门课的文字糊成一团，什么都读不出来 —— 而且你根本不知道「这底下还压着一门课」。

## 现在：一叠卡片

下层满宽满高，每往上一层，右侧和下边各缩 3dp，左上角对齐。

```
┌─────────────────┐   ← 下层（完整）
│ ┌─────────────┐ │
│ │  上层       │ │
│ └─────────────┘ │
└─────────────────┘
```

下层从右边和下边露出「厚度」，一眼能看出压着几门。

三种情况分开处理：

| 情况 | 排法 |
|---|---|
| 节次完全相同 | 卡片叠放 |
| 一大一小（短课整段落在长课里） | 卡片叠放，长的在下层 |
| 长度相近、只是错开 | 对称错位 10% |

## 轮换

每组重叠课程右下角有一个 ⇄ 按钮。点一下，最底层升到最顶层：

```
A-B-C  →  B-C-A  →  C-A-B  →  A-B-C
```

点三次回到原样。

**尺寸跟着层级走，不跟着课程走** —— 换到最上面的那门永远完整可见，被挡住的永远只是下层。

## 详情页

点任意一门课打开详情，顶部会多一条「重叠课程」，列出同一时段的所有课，点课名直接切换，不用关掉重开。

## 半透明格子

格子改成半透明，能透过上层看到下面的课。

这里踩过一个坑：一开始为了让「透视」更明显，把底色提到 0.78，结果橙色字压在橙色底上，几乎同色 —— 字反而读不出来了。现在底色压回浅，**文字用专门的阅读色**：

| 主题 | 字色 |
|---|---|
| 深色 | 保留课程色相，亮度拉到 ≥ 0.82 |
| 浅色 | 保留课程色相，亮度压到 ≤ 0.42 |

两套实测对比度分别是 6.6:1 和 5.4:1，都超过 WCAG AA 标准。

## 修复

- **点一组重叠课程的切换按钮，会把其他天的重叠组一起轮换**。原因是簇编号按天独立从 0 开始，周一第 0 组和周二的第 0 组撞了号。现在按「星期 + 当天序号」全局唯一编码。
- **点了按钮完全没反应**。`remember` 的 key 里放了 lambda，Compose 判定「没变」就不重算，状态变了界面不动。改成传 Map 快照。

## 去掉

标题栏那个「平铺 / 层叠」切换按钮 —— 平铺在半屏宽下字只能竖排，实际没人用得上，纯属干扰。
