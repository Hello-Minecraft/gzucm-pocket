# 广中医口袋 v1.2.3

这一版主要是**新增上课提醒**，顺带把首次进入的等待、断网可用性、电费页交互都补了一遍，并且修掉了几个一直存在的 bug（其中一个是通知权限从来没声明过，导致电费提醒其实一直没弹出来）。

> **非官方项目**，与广州中医药大学无隶属关系、未获授权。数据直连学校系统，不经过任何第三方服务器。

---

## 新增

### 上课提醒

课前提醒，公告栏里能看到课程名和上课地点，不用打开 App。

**提醒时机不是固定的 20 分钟**：

| 情况 | 提前量 |
|---|---|
| 当天第一节课（早八、下午第一节） | 20 分钟 |
| 上一节还没下课 | **10 分钟**（课间） |

判据是「T-20 分钟那一刻你人在不在教室」。比如 1-2 节 08:00–09:50、3-4 节 10:00 开始，T-20 = 09:40 还在上课，提醒就推到 09:50 的课间。

**通知内容**：

```
08:00 中医内科学
课室楼301·陈老师
```

标题是「时间 + 课程名」，第二行是「地点·教师」，授课内容在展开态里（MIUI 折叠态只给一行正文）。

用 `AlarmManager.setExactAndAllowWhileIdle` 定时，不是 WorkManager —— 后者最小周期 15 分钟且不保证准点，做不到课前 10 分钟。每次同步后重排未来 3 天，开机和覆盖安装也会自动重排。

设置里可以关掉，关掉会连带撤销已排的闹钟。

### 检查更新

「设置 → 关于软件 → 检查更新」，直连 GitHub Releases 查询最新版本。

- 版本号按数字段比较（`1.2.10 > 1.2.9`，按字符串比会错）
- 有新版本可直接下载 APK（走系统 DownloadManager，有通知栏进度，不需要存储权限）
- 连不上时按原因提示：`连不上 GitHub` / `连接超时` / `TLS 握手失败`，不丢一句「检查失败」了事

**直连的好处是没有第三方知道谁在用这个 App**；代价是国内网络可能不通，如果你打不开，就是网络问题，不是功能坏了。

### 首次进入不再长时间白屏

原来要等整学期 20 周的课表全抓完才渲染。现在分两阶段：

```
学期周历 → 当前周          → 立刻显示（2 次往返）
         → 其余 19 周并发   → 边到边更新进度
```

等待时有提示：呼吸点 + 轮播文案 + `第 N/20 周` 进度条。翻到还没到的周会显示「第 N 周还在路上」，不再是空白。

### 电费页

- **折线图可以左右滑动**选中某一天，竖线定位，日期与用量显示在图上方
- 显示**上次更新时间**（「更新」按钮左边的小字）
- 每月明细会缓存，重启后折线图和每日明细不再消失
- 「电费不准？」改成「**电费设置**」，里面加了**电费不足提醒开关**

## 修复

**通知权限从来没声明过。** `AndroidManifest.xml` 里少了 `POST_NOTIFICATIONS`，但代码一直在申请和检查它 —— 也就是说 v1.2.1 加的电费不足提醒，**从来没真正弹出来过**。现在声明了，并且打开任一提醒开关时会检查权限，没给会在设置里用红字提示并可点击授权。

**关于软件页下拉后点不动。** 下拉关掉面板时只清了一个状态标志，`showSettings` 还是 `true`，Compose 仍认为面板存在，留下一个透明遮罩盖在首页上 —— 界面在首页，但什么都点不了。

**断网时课表一直转圈。** 两阶段抓取引入的：从缓存恢复时没把「已到达的周」标记填满，每一周都被判成还在加载。现在缓存里的周直接算已到达。

**电费设置面板会突然消失。** 它的状态挂在列表项里，卡片滚出屏幕就被销毁。

**开关点起来卡卡的。** `Row` 上有 `clickable`、`Switch` 自己也有回调，一次点击翻两次。改成 Material 3 标准写法：`Row` 用 `toggleable`，`Switch` 的 `onCheckedChange = null`。

**登录过期提示每次打开都弹。** 改成只在同步失败时提示，且一天最多一次。

## 改进

- **周数以教务周历为准**：本学期实测 20 周（1–20 连续），之前代码写死 18
- **今天课上完后首页切到明日课程**，不用等到第二天
- **电费同步并入登录和手动同步**，不必等到"每天首次"
- 电费静默同步失败不再锁死一整天，改成 30 分钟后重试
- 空明细不再覆盖已有缓存

## 安装

- **Android 8.0（API 26）及以上**
- 可覆盖安装 v1.2.2，签名一致
- 首次使用需在应用内登录教务处，账号密码只在**学校认证页面**输入，App 不保存

---

## 已知限制

- **超级岛/焦点通知暂不支持**：客户端已按官方格式发送 `miui.focus.param`（以及系统应用实际使用的 `miui.focus.param.custom`），但小米要求企业主体 + 应用上架 + 邮件审核 + 设备白名单才给权限。没有权限时系统会静默降级成普通通知
- 电费依赖一卡通会话，登录过期后需重新登录才能刷新
- 每日明细只覆盖当前自然月
- 检查更新直连 GitHub，国内网络可能不通
