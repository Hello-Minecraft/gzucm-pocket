# 广中医口袋 v1.2.1 · 首个公开版本

广州中医药大学学生自用的 Android 客户端，把**教务系统**和**一卡通**的信息集中到一处。

> **非官方项目**，与广州中医药大学无隶属关系、未获授权。数据直连学校系统，不经过任何第三方服务器。

---

## 安装

- 系统要求：**Android 8.0（API 26）及以上**
- 直接安装 `gzucm-pocket-v1.2.1.apk`
- 首次打开需要在应用内登录一次教务处（账号密码只在**学校的认证页面**输入，App 不接触、不保存）
- 从旧版本升级可直接覆盖安装，签名一致

---

## 已实现功能

### 课表

**按周抓取，每节课都有具体内容**

不看学期总表，而是逐周请求。区别在于总表只有「这门课这学期上哪些周」，按周查才带每次课的具体内容：

| | 学期总表 | 按周查询 |
|---|---|---|
| 字段数 | 40 | **43** |
| 上课内容 `sknrjj` | 无 | **有** |
| 真实日期 `qsrq` | 无 | **有** |

举个实例：同一天两节「中医各家学说」，分别显示讲**王泰林**和**张锡纯**——这是总表表达不了的。

覆盖情况：2026-2027 第一学期，19 周共 233 课次，上课内容 / 真实日期 / 授课教师覆盖率均为 **100%**。

**其他课表功能**

- **水平翻页动画**：跟手拖动、松手按速度吸附、到边界回弹
- **自定义背景**：从相册选图，不透明度 15%–100% 可调
- 自动定位当前周，周次条点击跳转 / 左右箭头切换
- 星期行日期跟随滑动实时变化
- 课程详情：时间、日期、地点、教师、教学模式、教学环节、教学形式、合班、课时、课程号
- 「今日」页汇总当天课程与宿舍电量

### 成绩

- 课程成绩、等级成绩、体测成绩三类
- 列表滚动做了优化：排序/分组/统计量缓存、数字格式化改为整数运算、LazyColumn 补稳定 key

### 电费

- 剩余电量、近 7 天日均、可用天数、用电趋势图、当月每日明细
- **每天首次打开 App 时后台静默更新，不弹窗**
- 想立刻刷新可手动点更新
- **不足 3 天推送提醒**，同一数据不重复打扰
- 「电费不准？」说明：数据来源、到账时间、绑错房间、余额单位、免费电量、明细范围

技术实现上，一卡通的会话只存在于 WebView 的 Cookie 里，用 OkHttp 拿不到有效会话，所以在不可见的 WebView 里**劫持页面自己的 XHR 请求**，把响应回传给原生层解析。

### 通用

- 默认启动页可选（今日 / 课表 / 成绩 / 电费）
- 深浅色跟随系统
- 悬浮毛玻璃底栏、手势导航条适配、内容全屏
- 「设置 → 关于软件」内可查看历次更新日志
