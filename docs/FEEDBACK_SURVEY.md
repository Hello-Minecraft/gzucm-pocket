# 问题反馈问卷 · 设计与搭建说明

> 配套代码：`core/Feedback.kt`（问卷地址 + 版本号）、`ui/settings/FeedbackSheet.kt`（App 内那一屏）。
> 建完问卷只需要改 `Feedback.SurveyUrl` 一个常量，界面不用动。

## 一、为什么走问卷，而不是应用内直传

这个项目不维护服务器（`Updater.kt` 里写了理由：没有第三方能拿到谁在用这个 App）。为一年几十条反馈单独上一套后端，等于给自己加一个要续期、要盯着的东西。

问卷是现成的：不用备案、不用运维、免费、**填写不用登录**，还自带图片/视频上传和回复汇总。代价只有一个——用户点了会跳出 App，所以 App 里那一屏必须把**版本号**做成最大的字，让他跳出去之前就记住/复制。

## 二、平台选哪个

| 平台 | 文件/图片题 | 填写要登录 | 免费额度 | 结论 |
|---|---|---|---|---|
| **腾讯问卷** | 免费版支持（图片、视频、文件） | 不用 | 附件空间 2GB，**只保留 90 天** | **推荐** |
| 问卷星 | 免费版不支持文件上传（要付费版） | 不用 | 题目数、答卷数都有限制 | 备选，但图片题要钱 |

图片是排查问题的关键（课表错位、界面错乱，一张图胜过一百字），所以这里选**腾讯问卷**。

⚠️ 免费版的附件**只存 90 天**，到期自动删。每 2~3 个月进去导出一次（数据 → 下载）。

## 三、题目设计（照着填就行）

一共 5 道必答/选答 + 1 道建议加的类型题。

### 第 1 题 · 版本号 —— 必填

- **题型**：填空（单行文本）
- **题干**：`App 版本号`
- **提示语**：`打开 App → 设置 → 问题反馈，最上面那行大字就是，例如 1.3.6`
- **校验**：不限格式，别做正则（版本号格式以后可能会变）

> 这一题是整份问卷里最重要的。没有版本号，等于不知道你说的是哪个版本的 bug。

### 第 2 题 · 遇到的问题 —— 必填

- **题型**：填空（多行文本）
- **题干**：`遇到了什么问题？`
- **提示语**：`越具体越好：哪个页面、点了什么、屏幕上发生了什么。如果是课表或成绩不对，请说清是哪一门课 / 哪一天。`

### 第 3 题 · 希望的样子 —— 选填

- **题型**：填空（多行文本）
- **题干**：`你希望它变成什么样？`
- **提示语**：`可以只写一句，比如「希望周视图能直接看到教室」。`

### 第 4 题 · 截图 / 录屏 —— 选填

- **题型**：文件上传（图片 + 视频）
- **题干**：`传几张截图或一段录屏`
- **提示语**：`最多 3 个。发之前把学号、姓名、身份证号这些涂掉。`
- **限制**：单文件 ≤ 20MB，数量上限 3

### 第 5 题 · 联系方式 —— 选填，但建议填

- **题型**：填空（单行文本）
- **题干**：`怎么联系你？（选填，但强烈建议填）`
- **提示语**：`微信 / QQ / 邮箱都行。有些问题得再问一句才能定位，没联系方式就只能放着。`

### 第 6 题 · 问题类型 —— 建议加（必填，单选）

- **题型**：单选
- **题干**：`问题出在哪一块？`
- **选项**：`登录` / `课表` / `成绩` / `电费` / `界面与操作` / `其他`

**为什么值得多这一题**：一年几十条反馈，散着读很费劲；有这一题，你能直接看出「登录问题占了四成」，下个版本先修什么不用猜。这也是问卷相对「微信里随口说一句」的唯一结构性优势。

## 五、腾讯问卷搭建步骤

1. 打开 <https://wj.qq.com>，微信扫码登录
2. 新建 → 问卷 → 空白创建
3. 标题填 `广中医口袋 · 问题反馈`，把上面那段说明粘进「问卷说明」
4. 按第三节逐题添加（腾讯问卷里叫「填空题」「文件上传题」「单选题」）
5. 设置页里确认：
   - 允许匿名填写（默认就是）
   - 关掉「每台设备只能填一次」——同学换手机、重装都会踩到
   - 打开「新回复通知」（邮件或微信提醒）
6. 右上角「发布」→ 复制链接（形如 `https://wj.qq.com/s2/xxxxxxxx/xxxx/`）
7. 把链接填进代码：

```kotlin
// app/src/main/java/com/gzucm/pocket/core/Feedback.kt
const val SurveyUrl: String = "https://wj.qq.com/s2/xxxxxxxx/xxxx/"
```

改完重新打包即可。`Feedback.hasSurvey` 会自动从 `false` 变 `true`，App 里那个按钮就从「复制版本号」变成「打开问卷」。

## 六、上线后

- **每 2~3 个月导出一次附件**（免费版 90 天清空）
- 微信内置浏览器打开腾讯问卷有时会要求登录，让同学用系统浏览器打开更顺；App 里走的是 `ACTION_VIEW`，多数机型会直接拉起浏览器
- 别在问卷里承诺回复时效。App 内那一屏和问卷说明都写了「不保证回复」，这句是保护自己的
- 如果以后真要做「网页版课表导入」，那个托管地址可以顺便挂一个 `/feedback` 接口，届时这份问卷就可以退休

| 链接 | <https://wj.qq.com/s2/28748880/w40u/> |
| 二维码 | 桌面 `vibecoding/广中医口袋/反馈问卷-二维码.png`（转发/贴海报用） |
| 代码 | `core/Feedback.kt` → `SurveyUrl` 已填，`hasSurvey` 自动为 `true` |

`wj.qq.com/s2/` 是腾讯问卷的短链，扫同一个码和点同一个链进的是同一份问卷。链接本身很短（28 字符），真遇到浏览器打不开，用户手打也不难 —— 这也是选腾讯问卷而非长链自建页的一个附带好处。

**改题目不用改 App**：题目、选项、说明都在问卷后台改，App 只认这一个链接。反过来**换问卷才要重新打包** —— 老版本的 APK 里写死了旧链接，所以问卷别轻易删，重建就换一个 `s2` 号，老用户会打到 404。
